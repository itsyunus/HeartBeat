## 👻 What is this?

This repo exists solely to maintain my GitHub contribution streak.
A GitHub Actions workflow commits a heartbeat file here automatically — no local machine needed,
no servers, fully autonomous.

> *"Day by day, commit by commit."*

---

## ⚡ How it works

1. A scheduled GitHub Actions workflow fires twice daily
2. It writes a timestamped heartbeat to `HEARTBEAT.json`
3. Logs each day to `history/YYYY-MM-DD.json`
4. Commits and pushes with a randomized commit message
5. My GitHub contribution graph stays green 🔥

## 🔗 Tech

- **Zero dependencies** — pure GitHub Actions + bash + python3
- **Zero maintenance** — runs on GitHub's infrastructure forever
- **Zero cost** — GitHub Actions is free for public repos
- **Dual schedule** — backup run ensures no missed days
- **Manual trigger** — hit "Run workflow" anytime from the Actions tab
